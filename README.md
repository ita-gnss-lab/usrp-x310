# USRP X310 + TwinRX Configuration

Code for collecting data using a **USRP X310 with TwinRX** on Ubuntu, using either MATLAB or Python (see the branches).

Overall configuration steps:

1. Ubuntu Ethernet configuration for the X310
1. UHD connectivity checks
1. MATLAB Wireless Testbench support
1. External 10 MHz reference clock setup
1. Clock, time, and LO source configuration
1. TwinRX two-channel operation
1. GPS L1/L5 dual-frequency reception
1. LO/reference lock verification
