# USRP X310 + TwinRX Configuration

Short guide for configuring a **USRP X310 with TwinRX** on Ubuntu and MATLAB.

The document covers:

- Ubuntu Ethernet configuration for the X310
- UHD connectivity checks
- MATLAB Wireless Testbench support
- External 10 MHz reference clock setup
- Clock, time, and LO source configuration
- TwinRX two-channel operation
- GPS L1/L5 dual-frequency reception
- LO/reference lock verification

The JTAG/FPGA recovery procedure is intentionally not included.

## Files

- `main.tex` — complete step-by-step guide
- `main.pdf` — compiled version

## Build

```bash
pdflatex main.tex
```
