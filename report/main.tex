\abstract{This report describes the data recording process using the USRP X310 device. This reciver is placed in a fixed position in São José dos Campos, SP, Brazil, in the GPS/GNSS Laboratory at \gls{ita}\footnote{\url{https://github.com/ita-gnss-lab}}. The present report is updated as new recordings are made and new information is available.}

\section{Overview of the recordings}

The recording is computed automatically by a Linux service which is driven by the following guidelines:
\begin{itemize}
    \item Everyday, the program will start within the time rage [4PM, 6PM]
    \item It will sense whether the USRP is detectable via \texttt{uhd\_find\_devices --args=``addr=192.168.10.2''}.
    \item If not found, it will exit silently and will sense again in intervals of 15 min.
    \item Once found, a SigMF file will be created from the recording, with the interleaved I/Q samples + metadata, like number of channels (dual channel recording), frequency (L1 and L5), sampling rate (2MHz), sample type (signed 16-bit int), etc.
    \item Each record lasts 5 minutes (300 s)
    \item It will record a second time within the same range and 30 min after the first record, and then it will not record anymore for that day.
    \item After 15 days of records from the last report. Rubem will send an automatic message to header of the Laboratory, Prof. Dr. Felix Antreich, via WhatsApp with the summarized information from all recorded metadata;
\end{itemize}
